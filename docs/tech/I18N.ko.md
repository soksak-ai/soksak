# 국제화

이 문서는 [영어 정본](./I18N.md)의 한국어 번역입니다. 독립적인 규칙을 정의하지 않습니다.

## 독자가 소유 위치를 결정한다

사용자가 읽는 문장은 resource key가 소유합니다. 사용자와 LLM이 함께 읽는 문장도 같습니다. LLM만
읽거나 개발자만 읽는 문장은 영어 literal을 사용할 수 있습니다. 기본 언어가 영어라는 이유로 handler에
영어 label을 직접 쓰는 것도 지역화되지 않은 상태입니다.

## 두 mechanism, 하나의 규칙

짧은 label, message, refusal, description은 key table이 소유하며 읽는 순간 독자의 언어로 해석합니다.
문서는 영어 정본 하나와 필요할 경우 대응 `.ko.md` 번역을 가집니다. 번역은 영어 정본을 front matter에
명시하고 같은 section 순서와 의미를 유지하며 별도 규칙을 만들지 않습니다.

## Frontend

`frontend/src/i18n.ko.ts`가 기준 key set이며 `i18n.en.ts`는 모든 key를 가져야 합니다. React에서는
`useT()`, React 밖에서는 `tmsg()`, plugin manifest의 `LocalizedText`에는 `localize()`를 사용합니다.
Placeholder는 `{name}` 형식이며 모든 언어가 같은 placeholder set을 가져야 합니다.

## Go

Go package는 key와 언어별 table을 소유하고, 최종 독자가 확정된 boundary에서 문장을 render합니다.
Domain package는 완성된 사용자 문장을 framework로 보내지 않습니다. Error와 refusal은 key와 parameter를
보존하며 CLI, window, log 같은 독자 경계가 언어를 선택합니다.

## 사용자 언어 선택

명시적인 사용자 설정, account 설정, browser 또는 OS 설정 순서로 locale을 선택합니다. IP로 언어를
추측하지 않습니다. 선택된 언어에 key가 없으면 기본 locale을 사용하며 key 문자열 자체를 화면에
표시하지 않습니다.

## 검증

- 사용자 문장이 bundle을 우회하면 실패합니다.
- 기본 locale과 모든 locale의 key 수와 이름이 같아야 합니다.
- 같은 key의 placeholder set이 언어별로 같아야 합니다.
- Pseudo-locale로 길이를 늘려 layout overflow를 좌표로 검사합니다.
- 중요한 독자용 영어 문서는 필요한 `.ko.md` 번역과 canonical 연결을 가져야 합니다.

이 검증은 CI에서 반복 가능한 command와 test로 실행합니다.
