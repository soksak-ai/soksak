# baseline-unwrap — 파일별 `.unwrap(` 봉인 수. 이 파일은 봉인이지 해소가 아니다.
# 갱신은 --prune(축소)만. 값을 올리는 것은 명시 재입법 커밋으로만 한다(C5 — 무언 완화 금지).
# 제거 조건: 해당 파일의 `.unwrap(` 를 에러 전파/명시 처리로 대체 → stale 실패 → --prune. 0이면 항목이 삭제된다.
